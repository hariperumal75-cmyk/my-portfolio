# Hariperumal S N - Portfolio

A modern, responsive personal portfolio website showcasing my skills, projects, education, and contact information. Built with HTML, Tailwind CSS, and JavaScript, featuring a sleek dark theme with smooth animations and mobile-first design.

## Live Demo

[View Portfolio](https://hariperumal75-cmyk.github.io/protfolio/)

## Features

- **Responsive Design**: Optimized for all devices - mobile, tablet, and desktop
- **Dark Theme**: Modern dark UI with Material Design color system
- **Smooth Scrolling**: Seamless navigation between sections
- **Project Showcase**: Featured projects with live demos and source code links
- **Skills Section**: Comprehensive display of technical skills and tools
- **Quality Focused**: Projects manually tested across devices and browsers
- **Contact Form**: Interactive contact form for inquiries
- **Performance Optimized**: Fast loading with minimal dependencies
- **Modern Typography**: Using Inter and Plus Jakarta Sans fonts

## Technologies Used

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework
- **JavaScript (ES6+)** - Interactive functionality
- **Testing & QA** - Manual website testing, cross-browser and cross-device QA
- **Material Symbols** - Icon library
- **Google Fonts** - Typography

## Getting Started

### Prerequisites

- Node.js (optional, for local dev server)
- A modern web browser

### Installation

1. Clone the repository
```bash
git clone https://github.com/hariperumal75-cmyk/protfolio.git
cd protfolio
```

2. Open `index.html` in your browser, or run a local server:

**Using Python:**
```bash
python -m http.server 8000
```

**Using Node.js (with npx):**
```bash
npx serve .
```

**Using Vite (recommended for development):**
```bash
npm install
npm run dev
```

3. Visit `http://localhost:8000` in your browser

## Development

### Build for Production
