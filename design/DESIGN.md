## Brand & Style

This design system defines a high-conviction, engineered aesthetic tailored for a technical full-stack developer portfolio. It rejects generic templates in favor of a modern architectural sensibility: structured, data-informed, and calm yet precise. 

The aesthetic sits at the intersection of **Corporate Modernism** and **Technical Futurism**. It communicates deep engineering mastery through deliberate micro-interactions, subtle photonic glow cues, disciplined typographic hierarchy, and structural border alignment. 

The emotional tone balances analytical rigor with welcoming approachability. Whitespace functions as structural punctuation rather than empty room, framing code artifacts, architectural case studies, and engineering metrics with executive-level clarity.

## Colors

The system employs a dual-mode blue spectrum calibrated for technical legibility and chromatic balance across dark and light canvases.

### Dark Mode (Default)
- **Canvas Base (`bg`):** `#0B1120` — Deep obsidian blue providing maximum ambient depth.
- **Canvas Alternate (`alternate bg`):** `#101A2E` — Layered background tier for code playgrounds and section blocks.
- **Surface Elevation (`card`):** `#131F33` — Elevated structural container surface.
- **Text Primary:** `#F1F5F9` — High-contrast slate for headlines and structural copy.
- **Text Secondary:** `#A6B4C8` — Muted silver-blue for metadata, tags, and descriptive copy.
- **Primary Technical Blue:** `#60A5FA` — Vibrant cyanic blue for actionable interactive states and hero elements.
- **Accent Blue:** `#3B82F6` — Focused mid-tone electric blue for secondary interactive cues.
- **Structural Border:** `#26364F` — Controlled low-luminance divider line.
- **Atmospheric Glow / Soft Highlight:** `#172D4F` — Deep indigo-tinted blue for badge fills, interactive halos, and card highlights.

### Light Mode
- **Canvas Base (`bg`):** `#F7F9FC` — Crisp, cool clinical white-tint.
- **Canvas Alternate (`alternate bg`):** `#EEF3FA` — Soft cool wash for modular segmentation.
- **Surface Elevation (`card`):** `#FFFFFF` — Pure optical surface.
- **Text Primary:** `#172033` — Deep midnight navy for stark, distraction-free reading.
- **Text Secondary:** `#64748B` — Neutral steel tone for meta-information.
- **Primary Technical Blue:** `#2563EB` — Punchy royal blue providing WCAG AAA compliant contrast.
- **Accent Blue:** `#3B82F6` — Bright interactive secondary blue.
- **Structural Border:** `#DCE5F0` — Fine hair-thin container border.
- **Atmospheric Glow / Soft Highlight:** `#DBEAFE` — Air-tinted ice blue for active chips, hovered surfaces, and badge fills.

### Rules of Engagement
- Primary blues (`#60A5FA` / `#2563EB`) must be reserved strictly for key interactive anchors, active tabs, and primary action triggers.
- Soft highlight tiers (`#172D4F` / `#DBEAFE`) form the background of inline code badges, metric highlights, and pill selectors. Never use raw opacity fades over high-contrast text.

## Typography

The typography pairing reflects technical clarity. **Plus Jakarta Sans** governs titles, section headers, and statistical values—offering modern geometric posture with engineered curves. **Inter** handles narrative prose, UI controls, project metadata, and code annotations, ensuring clinical legibility at compact body scales.

### Typographic Disciplines
- **Optical Kerning & Tracking:** Display hierarchies use tight tracking (`-0.03em` to `-0.015em`) to compress visual rhythm, conveying editorial confidence. Labels and tiny indicators use expanded positive letter spacing for rapid scanning.
- **Monospaced Utility:** Code blocks and repository statistics leverage tabular numbers (`font-variant-numeric: tabular-nums`) within the primary font for aligned data grids.

## Layout & Spacing

The layout is constructed on an adaptive 12-column grid system capped at a maximum content width of 1200px.

### Breakpoints & Columns
- **Desktop (≥ 1024px):** 12 columns, `1.5rem` gutter, `3rem` canvas margin. Case studies, architecture timelines, and stack modules deploy 2-column or 3-column asymmetric splits.
- **Tablet (768px – 1023px):** 8 columns, `1.25rem` gutter, `2rem` canvas margin. Sidebars fold into linear stacks.
- **Mobile (< 768px):** 4 columns, `1rem` gutter, `1.25rem` canvas margin. Strict single-column stack flow with horizontal scrolling cards for compact technical taxonomies.

### Spacing Cadence
All spatial relationships respect an 8pt baseline scale. Internal card padding is strictly pegged between `space-md` (compact cards) and `space-lg` (featured showcase modules). Section-to-section breaks use multiples of `space-xl` (5rem to 7.5rem) to preserve breathable pacing.

## Elevation & Depth

Visual depth avoids excessive heavy black drop shadows. Depth is achieved via **tonal surface separation**, **1px crisp borders**, and **subtle directional photonic blue glows**.

### Dark Mode Elevation Hierarchy
- **Level 0 (Canvas):** Flat `#0B1120`.
- **Level 1 (Card & Modular Panel):** Background `#131F33`, enclosed by a 1px border in `#26364F`.
- **Level 2 (Hovered Card / Active Panel):** Background `#131F33`, border shifts to `#3B82F6` (35% opacity), accompanied by an ambient photonic shadow: `0 8px 30px -8px rgba(59, 130, 246, 0.15)`.
- **Level 3 (Modal / Floating Nav / Quick Switcher):** Translucent backdrop blur (`backdrop-filter: blur(16px)`), background `rgba(19, 31, 51, 0.85)`, border `rgba(59, 130, 246, 0.25)`, shadow: `0 20px 40px -12px rgba(0, 0, 0, 0.5)`.

### Light Mode Elevation Hierarchy
- **Level 0 (Canvas):** Flat `#F7F9FC`.
- **Level 1 (Card):** Background `#FFFFFF`, enclosed by a 1px border in `#DCE5F0`, faint ambient shadow: `0 2px 8px -2px rgba(23, 32, 51, 0.04)`.
- **Level 2 (Hovered Card):** Border shifts to `#3B82F6` (50% opacity), shadow transforms to: `0 12px 28px -6px rgba(37, 99, 235, 0.12)`.
- **Level 3 (Floating Nav / Drawers):** `rgba(255, 255, 255, 0.9)` with `blur(16px)`, border `#DCE5F0`, shadow: `0 16px 32px -8px rgba(23, 32, 51, 0.08)`.

## Shapes

The geometric framework balances human warmth and architectural structure.

- **Interactive Core (Buttons, Text Inputs, Segmented Controls):** `8px` (`0.5rem`) corner radius. This conveys sharp functional utility without stark utilitarian harshness.
- **Containers & Project Cards:** `12px` (`0.75rem`) to `16px` (`1rem`) corner radius. Feature modules adopt `16px` to clearly distinguish large spatial boundaries from smaller inner components.
- **Pills, Badges & Theme Switcher:** Fully rounded pill radius (`9999px`) to immediately signal category tags, tech-stack markers, and status indicators.

## Components

### 1. Buttons
- **Primary Action:** Solid fill with Primary Blue (`#60A5FA` dark / `#2563EB` light). Contrasting text (`#0B1120` dark / `#FFFFFF` light). Height: 42px. 8px radius. Active state produces a gentle 0 0 16px glow in primary blue.
- **Secondary Action:** Ghost surface with 1px border (`#26364F` dark / `#DCE5F0` light). Foreground: primary text. Hover: border shifts to accent blue with faint background highlight (`#172D4F` dark / `#DBEAFE` light).
- **Icon Action:** 40px square, 8px radius, border matching secondary button. Centered technical icons with smooth color transitions.

### 2. Developer Project Cards
- **Base Style:** 16px corner radius, 1px border. Background set to card tier (`#131F33` dark / `#FFFFFF` light).
- **Header Structure:** Title in `headline-sm`, complemented by an active repository status indicator (glowing 6px emerald dot for live deployments).
- **Tag Row:** Row of technology chips anchored to the lower card edge with `space-sm` gap.
- **Interactive State:** `translateY(-3px)` lift on hover with the designated elevation level 2 blue ambient glow.

### 3. Tech Stack & Filter Chips
- **Neutral State:** Pill shape (`9999px`), 6px vertical padding, 12px horizontal padding. Border: 1px subtle. Typography: `label-sm`.
- **Active State:** Solid soft blue highlight fill (`#172D4F` dark / `#DBEAFE` light) with bold primary blue typography and border.

### 4. Form Controls & Inputs
- **Text Inputs & Textareas:** 8px radius, 1px border (`#26364F` dark / `#DCE5F0` light), card surface background. Placeholder text set to secondary text.
- **Focus State:** 1px solid Primary Blue with a 3px outer halo in `rgba(96, 165, 250, 0.2)` (dark) or `rgba(37, 99, 235, 0.15)` (light). Never outline with jarring browser defaults.

### 5. Checkboxes & Radio Controls
- **Size:** 18px square (checkbox) or circle (radio), 4px radius for checkbox.
- **Checked State:** Primary blue fill with white technical checkmark or center pip. Border color matches primary blue.

### 6. Interactive Theme Toggle
- **Architecture:** Compact segmented pill (`9999px`), containing sun/moon iconography.
- **Surface:** Card background with 1px structural border.
- **Active Thumb:** Spring-animated pill background (`#172D4F` dark / `#DBEAFE` light) with accent blue icon tint, providing unambiguous physical indication of the active mode.

### 7. Code Snippet Blocks & Architecture Callouts
- **Header:** Terminal-style window bar containing directory path in `code-inline` typography and an integrated "Copy Code" button.
- **Body:** `#101A2E` dark surface (or `#EEF3FA` light surface) with distinct left border accent (2px solid Primary Blue).
